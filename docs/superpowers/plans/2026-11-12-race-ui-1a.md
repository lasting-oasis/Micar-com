# Race UI stage 1a Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the Strip's circuit, sprint and street X races a Slipstream-style race HUD, five start lights, lap, sector and gap timing, and new results and pause screens. MiCar's cars, physics and engine sound are unchanged.

**Architecture:**
- A pure timing module records, for every car, when it crosses each sector boundary and each 10 m of race distance. `EventRunner` steps it, and the standings carry best laps and gaps in seconds.
- A pure lights helper drives the count for lap-race types.
- The HUD canvas gets a race layout, built from a pure view model (`raceView`) and drawn by `drawRaceHud`.
- The results and pause screens stay React overlays. Their rows come from pure, tested builders.

**Tech Stack:** TypeScript 5.9, React 18, Tailwind 3, zustand 4, the 2D canvas, vitest 2, Playwright 1.63 (e2e).

**Spec:** `docs/superpowers/specs/2026-11-12-race-ui-design.md`, sections 6.1–6.3, 6.5, 6.6, 6.8, 6.9, 7 and 11 (1a only).

## Global Constraints

- **Lap-race types:** the new HUD and lights cover `circuit`, `sprint` and `streetx` only. Drag, drift, outrun and free roam keep today's HUD, with panels restyled.
- **Frame budget:** draw on the existing HUD canvas. Nothing re-renders through React per frame, and the HUD costs no more per frame than today's.
- **Language:** every new string comes in English and Spanish (`i18n.tsx` `DICT`; the HUD canvas uses `HUD_TXT`).
- **Dependencies:** none added or upgraded.
- **Tests:** existing tests stay green, except the countdown expectations this plan changes on purpose.
- **Challenges:** the protocol is unchanged and the server's green time is authoritative. Lights go out exactly at `goAt()`.
- **Brand:**

  | Name | Value |
  |---|---|
  | night | `#0e1217` |
  | panel | `rgba(14,18,23,.9)` |
  | line | `#262d37` |
  | ink | `#e7eaee` |
  | haze | `#9aa3ad` |
  | accent | `#ffd23f` |
  | info blue | `#79a6ff` |
  | personal best | green `#2bd66b` |
  | race fastest | purple `#b25cff` |
  | warning | red `#ff5a6a` |

  Type: Barlow Condensed (italic 800–900) for numbers and headings, Barlow for labels.
- **No Slipstream marks:** no red slash logo, no Titillium Web, no Slipstream names.
- **Commits:** none until the owner asks. Work stays on branch `race-ui-stage-1a`.

## Review Focus

1. **Back-row starts.** Cars start up to 8 m behind the line (s < 0). Lap 1 must end at s = lap length, not at the start (Task 1).
2. **Wrong way or reversing across a boundary** must not count a lap or sector twice (Task 1).
3. **A challenge green named late, or re-named later by the server.** The lit count must never go down during the count, and lights go out at the named instant (Task 2).
4. **A racer with no usable distance** (stuck, parked after a DNF, a person whose poses stopped) shows an empty gap, never NaN, Infinity or a negative zero (Task 4).
5. **Narrow phone screens (844×390, 390×844) and the longer Spanish labels** must not overlap the tap buttons, the car panel or each other (Task 8 screenshots).

**Interfaces:**
- Produces:
  ```ts
  export const SECTORS = 3;
  export const MARK_M = 10;
  export type SectorMark = 'open' | 'plain' | 'pb' | 'best';
  export class RaceTiming {
    constructor(lapLen: number, loop: boolean);
    /** s: race distance in m, cumulative across laps (may start below 0); t: race time in s */
    step(key: string, s: number, t: number): void;
    laps(key: string): number;                        // completed laps (loop only; 0 for a sprint)
    lapTime(key: string, now: number): number;         // time into the current lap (sprint: since the start)
    last(key: string): number | null;
    best(key: string): number | null;
    fastest(): { key: string; time: number } | null;
    /** the current lap's sectors, length SECTORS */
    sectors(key: string): { time: number | null; mark: SectorMark }[];
    /** seconds `behind` trails `ahead` (now − when `ahead` passed `behind`'s distance); null if unknown */
    gap(behind: string, ahead: string, now: number): number | null;
  }
  ```

- [ ] **Step 1: Write the failing tests** in `timing.test.ts`, with these helpers:
  - `drive(T, key, v, s0, until, dt)` steps a car at constant speed `v` from `s0`.
  - The lap length is 1000 m.

  The tests:
  - `counts and times laps at constant speed`: 50 m/s, dt 0.1, until 41 s → `laps('a')` 2, `last('a')` and `best('a')` ≈ 20 (±1e-9).
  - `interpolates a crossing between coarse steps`: dt 0.7 → `last('a')` ≈ 20 (±1e-9).
  - `a back-row start ends lap 1 at the line, not at the start`: from s0 = −8 → `laps('a')` is 0 at t = 0.1 and 1 at t = 20.3. `last('a')` ≈ 20.16, which includes the 0.16 s spent covering the 8 m behind the line.
  - `does not count a boundary twice when the car goes back over it`:
    - steps (s, t): (995, 1), (1005, 2), (995, 3), (1010, 4)
    - → `laps('a')` 1, and the only completed lap time ends at the first crossing
  - `splits the lap into thirds and marks sectors`:
    - lap 1 at 50 m/s, then sector 2 of lap 2 at 100 m/s for car a
    - → in lap 2, `sectors('a')[1].mark` is `'best'`, and `[0].mark` is `'plain'` once a second car has set a quicker sector 1
    - a sector equal to the car's own best but not the race's is `'pb'`
  - `gives the gap in seconds`:
    - a from 0 and b from −100, both at 50 m/s, until 10 s → `gap('b', 'a', 10)` ≈ 2.0 (±0.01)
    - `gap('a', 'b', 10)` is null
  - `knows the race's fastest lap`: two cars, b faster → `fastest()` returns `{ key: 'b', time: … }`.
  - `a sprint has sectors but no laps`: `new RaceTiming(1000, false)` → `laps` stays 0, `last` is null, and three sector times are set by s = 1000.

- [ ] **Step 2: Run them to see them fail**

  Run: `cd apps/sim && pnpm exec vitest run src/world/strip/timing.test.ts`
  Expected: FAIL, cannot find module `./timing`.

- [ ] **Step 3: Implement `RaceTiming`.** For each car, keep:
  - the last `(s, t)`
  - the next boundary index: boundaries sit at k × lapLen / 3, for k ≥ 1
  - a `marks: number[]` of the time at each `MARK_M` metres, from 0

  On `step`:
  - Ignore any s at or below the furthest s seen; this handles going backwards.
  - Linearly interpolate the crossing time of every boundary and mark passed.
  - Lap k ends at the boundary k × SECTORS. Lap 1 starts at t = 0.
  - Sector marks:
    - `'best'` when the time equals the race's minimum for that sector index
    - `'pb'` when it equals the car's own minimum
    - `'plain'` otherwise
    - `'open'` when not yet run this lap

  `gap(b, a, now)`: interpolate `a`'s time at `b`'s furthest s from `a.marks`. Return null if `a` hasn't reached it or `b` has no steps.
