# Race selector and race map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** A Races screen laid out like Slipstream's circuit screen, and a circuit-outline race map, in MiCar's look.
**Architecture:** Python writes the map data from the circuit json; a pure TS model builds what the screen shows;
a React overlay draws it and starts races through the existing quick path; the canvas HUD draws the outline map.
**Tech Stack:** Python 3 (pytest), TypeScript, React 18, Tailwind, vitest, Playwright smokes.
**Spec:** `docs/superpowers/specs/2026-11-13-race-menu-design.md`

## Global Constraints
- No new dependencies. Every new string in English and Spanish (`i18n.tsx`).
- No Slipstream marks: no red slash logo, no Titillium Web, no Slipstream names. MiCar's brand tokens and fonts.
- Phones and desktops equal: touch targets at least 44 px; keyboard: arrows, Enter, Esc, T.
- Today's tests stay green; nothing re-renders through React every frame.

## Review Focus
1. Opening the menu during a live event, a challenge race, the pause screen or results: it must not open.
2. A guest with no car out: Start must not start anything (it reads "Pick a car first").
3. Keys while the menu is open: Enter/Esc/arrows must not also reach the game (pause, enter, steering).
4. Phone portrait and short landscape (844×390, 667×375): nothing overlaps; cards scroll; Start reachable.
5. The race map for a sprint (open route) and for a figure-eight crossing; a car far off the route.

### Task 1: Circuit map data
**Files:** Create `tools/blender/circuit_maps.py`, `tools/blender/test_circuit_maps.py`,
`apps/sim/src/world/strip/circuitMaps.json`.
**Produces:** `circuitMaps.json` = `{ version: 1, circuits: { [trackId]: { len: number, pts: [x, z][] (180, closed,
first = start line), sectors: [i2, i3] (indices where sectors 2 and 3 start), corners: [x, z][] (apexes in order) } },
events: { [eventId]: [x, z][] (≤ 120) } }`, game coordinates rounded to 0.1 m.
*As built:* each corner is `[ax, az, lx, lz]` (the apex and where its number sits, kept 3% of the circuit's diagonal
from other numbers), and each event is `{ loop, pts }`.
- [ ] Tests: every circuit and every event in tracks.json present; 180 points; outline length within 2% of `lenM`;
  sectors at 60 and 120; corners between 6 and 30 per circuit, each within 3 m of the centre line, in order along it;
  deterministic (two runs, same bytes). Watch them fail; implement; pass; write the json.

### Task 2: The menu's model
**Files:** Create `apps/sim/src/world/raceMenu.ts`, `raceMenu.test.ts`; modify `i18n.tsx`.
**Consumes:** `EVENTS`, `TRACK_NAMES`, `EV_NAME`, `EV_COL`, `stageOf`, `StripRecord`, tracks.json, circuitMaps.json.
**Produces:** `CIRCUITS` (order, country codes, names, blurbs); `circuitView(id, lang, rec, units, maps)`;
`eventViews(id, lang, rec)`; `firstCircuit(rec, lastEventId)`; `menuKey(state, key) -> state | action`;
`startAction(evId, rec, canDrive) -> 'start' | 'locked' | 'needCar'`; `fmtTime(s)`.
- [ ] Tests: ten circuits in tracks.json order; names and countries in both languages; stats (length in km and
  miles, corners, events, best = the lowest best of its events or none); events with locks by stage and bests;
  first circuit = last raced, else first with an unwon unlocked lapped event, else the first; keys: ←/→ wrap, Enter
  goes circuit → event → start, Esc goes event → circuit → close; start refused when locked or without a car.

### Task 3: The Races screen
**Files:** Create `apps/sim/src/world/RaceMenu.tsx`; modify `driveUi.ts` (`racesOpen`, tap `'races'`),
`input.ts` (KeyT → edge `races`), `DriveLayer.tsx` (RACES tap button, mount), `VanillaThreeScene.tsx` (toggle on
the edge or tap where allowed; freeze while open; ignore the game's keys while open; start = `quick`).
- [ ] Hero, SVG map (sectors, corner numbers, start line, legend), circuit cards, event cards, hints; phone layout.
- [ ] Wiring as above; it never opens during a live event, a challenge, pause or results.

### Task 4: The race map
**Files:** Modify `apps/sim/src/world/hud.ts` (lap races draw the outline), `raceHud.ts` (`fitRoute`),
`raceHud.test.ts`.
**Produces:** `fitRoute(pts, cx, cy, w, h, pad) -> { s, ox, oz }` (uniform scale, centred, every point inside).
- [ ] Test `fitRoute` (aspect kept, inside the box, centred); draw: dark edge + white line, start tick, dots
  (racers in their colours, people, the player in yellow on top); radar unchanged elsewhere.
